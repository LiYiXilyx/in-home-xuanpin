# 连续采集跟踪

在运营台“周期跟踪”选择正式商品池创建计划。计划固定当时的商品列表和基线。

每次手动采集后，运营台约每60秒同步已保存的来源记录；也可点“刷新记录”立即同步。隔天、同一天多次、第21天以后均可记录。不启动浏览器采集，不自动点击 Temu。

- 默认“最新数据 vs 基线”展示最新一次实际观测的指标变化。
- 点商品“查看”可切换价格、展示销量、评论数、评分曲线，横轴是实际采集时间。
- 下方历史表展示全部观测及相对上一次观测的变化。缺失指标不沿用旧值，不虚构变化。
- 同一来源记录重复同步不重复入库；不同时间重新采到同样数值仍保留一条观测。
- 原7/14/21天视角保留：仍取各阶段窗口内首条记录，完整历史不受这些窗口限制。
- Excel“周期变化”新增最新观测对比，“观测记录”导出完整连续历史。
- 暂停计划期间不新增同步；恢复后会同步来源数据库保留的计划开始以来记录。
- 计划开始之前的采集不倒灌为新观测；旧基线与已有阶段记录保留。没有采集到不等于商品下架。
- 展示销量可能取整，差额不代表精确成交量；不同币种不计算价格差额。

数据保存在 state/data/period-tracking.db 的 tracking_observations 表，旧 tracking_points 保留兼容。
