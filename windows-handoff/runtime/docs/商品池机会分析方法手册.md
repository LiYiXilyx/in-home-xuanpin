# 如何使用这本手册

这不是一套脱离实际的新流程，而是把一次完整商品池分析中反复验证、修正过的判断方式整理成可复用技巧。它回答四个问题：市场有没有容量、竞争是否真实可进入、产品是否适合你的履约方式、最后该落到哪些具体商品。

| 你要回答的问题 | 对应动作 | 最容易犯的错 |
| --- | --- | --- |
| 市场大不大？ | 看总销量、GMV和中位销量 | 只看头部爆款 |
| 竞争强不强？ | 看细分产品数、Top3占比和GMV/SKU | 把大类低集中当成细分低竞争 |
| 能不能做？ | 拆重量体积、车型适配、评论与IP风险 | 只按名称或平台类目判断 |
| 先做什么？ | 先选产品类型，再选代表性商品 | 直接把销量最高的链接当机会 |

## 一条主线：四层下钻

## 1. 第1层｜整个商品池：确认数据边界与整体结构。

## 2. 第2层｜真实消费场景：判断钱和需求流向哪里。

## 3. 第3层｜细分产品类型／物理形态：识别真正的竞争单元。

## 4. 第4层｜具体商品：选出可验证、可跟进的代表性链接。

|  | 关键原则 机会判断必须在“细分产品类型”层完成；大场景只能用来决定往哪里继续挖，不能直接得出某个产品值得进入。 |

# 1. 第一步：先把数据变得可信

## 1.1 必须保留的原始字段

商品名、商品链接、图片、价格、累计销量、评分、评价数。

平台类目可以保留，但只作为参考字段，不能直接充当最终分类。

如有重量、包装尺寸、车型、品牌、上架时间，应一并保留；没有时必须标注“未知”，不要推测成事实。

## 1.2 清洗检查

| 检查项 | 处理方式 |
| --- | --- |
| 价格 | 统一币种；剔除空值、0元、明显异常值；记录促销价口径 |
| 销量 | 确认是累计销量还是周期销量；文本数字转成数值 |
| 评分与评价 | 空值不当作0分；评价数不能替代销量 |
| 重复商品 | 按链接去重；同款不同规格是否合并需单独说明 |
| 图片与链接 | 保留为可点击/可查看的证据，避免只输出抽象结论 |

|  | 口径提醒 估算GMV = 当前价格 × 累计销量。它用于商品池内部横向比较，不等于真实周期销售额，也不包含优惠、退款、税费和平台扣点。 |
| --- | --- |

# 2. 第二步：按真实消费场景重分类

平台类目常按站内管理逻辑组织，同一消费场景可能被拆散，同名关键词也可能造成误判。应先问“用户为什么买”，再问“它是什么形态”。

| 一级场景 | 典型细分产品 |
| --- | --- |
| 骑行电子 | 蓝牙耳机、手机支架、导航/仪表、行车记录、电子防盗 |
| 骑行收纳 | 尾包、油箱包、边包、工具收纳包、硬箱与安装架 |
| 维修保养 | 补胎套装、链条工具、火花塞工具、清洁养护、维修组合工具 |
| 安全防护 | 轻小防摔件、车身保护件、重型护杠、车罩、防盗锁 |
| 照明 | 前照灯、辅助灯、转向灯、尾灯、灯罩/支架 |
| 电气供电 | USB充电器、点烟器、电压表、线束、开关、继电器 |
| 控制操纵 | 手把、拉杆、脚踏、换挡/刹车控制件 |
| 外观改装 | 贴花、装饰盖、风挡、后视镜、车身造型件 |

## 2.1 两段式分类法

## 1. 先用规则和关键词做初分，快速覆盖大部分商品。

## 2. 再对高GMV、高销量、模糊命名和边界品逐条复核图片与标题。

## 2.2 昨天分析中最有价值的误判纠正

| 容易误分的词/商品 | 正确判断 |
| --- | --- |
| 标题出现 reflective | 可能只是车罩反光条，不应自动归入照明 |
| 标题出现 polished | 可能指抛光表面，不等于清洁养护 |
| air cleaner | 通常是空气滤清器，不是清洁剂 |
| tool bag | 是工具收纳，不等于维修工具套装 |
| crash bar bag | 是装在护杠上的包，不是护杠 |
| ignition alignment tool | 是维修工具，不是电气供电商品 |

# 3. 第三步：建立一套不偏科的指标

| 指标 | 公式/口径 | 它真正回答什么 |
| --- | --- | --- |
| 商品数 | 细分类型内有效SKU数 | 同质竞争密度；不是卖家数 |
| 总销量 | Σ销量 | 池内需求规模 |
| 平均销量 | 总销量÷商品数 | 总体产出，但易被爆款拉高 |
| 中位销量 | 销量排序后的中间值 | 普通商品的真实表现 |
| 平均售价 | Σ价格÷商品数 | 价格带和商业空间 |
| 估算GMV | Σ(价格×销量) | 需求与客单价结合后的价值规模 |
| GMV/SKU | 估算GMV÷商品数 | 每个在售商品可分到的价值 |
| 平均评分 | 有效评分均值 | 成熟度与用户满意门槛 |
| 平均评价数 | Σ评价数÷商品数 | 社会证明壁垒 |
| 评论密度 | Σ评价数÷Σ销量 | 每单位销量形成多少评价；需同池比较 |
| Top3销量占比 | 销量最高3款÷总销量 | 头部对需求的控制程度 |

|  | 为什么一定要看中位数 如果平均销量很高、但中位销量很低，说明市场可能靠少数爆款支撑。对新进入者来说，中位销量通常比平均销量更接近可实现水平。 |
| --- | --- |

# 4. 第四步：用机会指数排序，但不让高销量“通吃”

机会指数只负责统一比较尺度，不代替业务判断。所有分项先在同一分析层级内做0—100分位标准化；销量、GMV和评价数使用对数后再排名，降低头部极端值的影响。

| 维度 | 权重 | 内部构成 |
| --- | --- | --- |
| 需求强度 | 25% | 总销量60% + 中位销量40% |
| 商业价值 | 20% | 平均售价55% + GMV/SKU 45% |
| 进入友好度 | 25% | 商品数反向55% + Top3占比反向45% |
| 评论空白 | 15% | 平均评价数反向60% + 评论密度反向40% |
| 质量基础 | 15% | 平均评分 |

建议只给样本数不少于3个商品的细分类型正式排名；样本更少的品类列入“验证机会”，避免因为偶然样本被打高分。

## 4.1 机会分数的正确读法

高分 ≠ 立刻开发；它表示值得优先核查供应链、物流、适配和IP。

同分时，优先看中位销量更高、Top3更低、GMV/SKU更高的品。

评分高不是差异化机会；它可能意味着用户要求高、成熟度高。

评论密度低可能是评论壁垒低，也可能是低参与度或异常销量，必须与评价绝对数、评分一起看。

# 5. 最关键的技巧：大类低集中，不等于细分好进入

“安全防护GMV最高、Top3占比最低、价格带合适”可以说明这个方向值得继续挖，但不能证明每一种安全防护产品都容易进入。大类混合了车罩、轻小防摔件、护杠、防盗等不同需求，Top3会被自然摊薄。

## 5.1 正确的下钻顺序

## 1. 先看一级场景的容量：总销量、GMV、价格带。

## 2. 再按用户用途与物理形态拆成细分产品。

## 3. 在细分内重算商品数、GMV、GMV/SKU、中位销量和Top3。

## 4. 最后打开头部链接，判断集中来自产品、品牌、车型还是单条链接。

| 观察组合 | 更可能的解释 | 下一步 |
| --- | --- | --- |
| 大类Top3低，细分Top3也低 | 需求分散，竞争相对开放 | 优先看供应链和差异化 |
| 大类Top3低，细分Top3高 | 大类稀释造成假象 | 拆品牌、车型、功能与渠道 |
| Top1>50%，其余品牌分散 | 单链接强势，不一定是行业垄断 | 看上架时间、素材、价格与评论积累 |
| 同一品牌多条链接共同占据头部 | 可能存在品牌/渠道/系统壁垒 | 做品牌与IP核查 |

# 6. 如何判断“头部偏强”到底是什么原因

以工具收纳包为例，头部偏强可能来自四种完全不同的原因。只有把原因分清，才能判断它是“可复制的好机会”还是“看起来诱人、实际难进”。

| 原因 | 识别信号 | 机会含义 |
| --- | --- | --- |
| 单链接运营优势 | 一个链接占比高，但品牌不连续；造型常规 | 可能可复制，重点学价格、图片、评价积累 |
| 品牌/渠道垄断 | 同品牌多款占据头部，价格体系稳定 | 需要品牌力或渠道成本，不宜只做同款 |
| 车型/安装系统壁垒 | 依赖专用支架、接口、生态配件 | 需掌握适配表和配套系统 |
| 知识产权壁垒 | 独特结构、外观、商标或受保护图案反复出现 | 未经检索不能视为低风险 |
| 大类口径过宽 | 不同用途商品被放在一起 | 重新拆细分后再谈集中度 |

|  | 结论条件 只有在“细分容量足够 + 头部强但优势可复制 + 无明显品牌/IP/系统壁垒”同时成立时，行业集中才可能转化为进入机会。低集中本身也不等于低IP风险。 |
| --- | --- |

# 7. 物流形态必须单独拆：尤其是防摔与收纳

同属安全防护或骑行收纳的商品，履约模型可能完全不同。只按用途合并，会把轻小件和大体积钢制件放进同一个机会分数里，造成错误结论。

| 物流形态 | 典型商品 | 主要风险 | 判断动作 |
| --- | --- | --- | --- |
| 轻小件 | 轴滑块、防摔球、护罩、小型保护片 | 适配错误、低价竞争 | 核车型、材质、安装位置、包装重量 |
| 软包/可压缩 | 工具包、尾包、油箱包、边包 | 面料、防水、绑带强度 | 核容量、展开/压缩体积、安装方式 |
| 重型/大体积 | 整车护杠、硬箱、安装架、大型护网 | 实重、抛重、运费、破损 | 核单件重量、包装尺寸、可拆装程度、仓配成本 |

## 7.1 防摔护杠是否只能走海外仓？

不能仅凭“护杠”名称下结论。重型护杠通常更适合海外仓或平台仓，但是否“只能”如此，要比较实重与体积重、跨境直邮计费、当地仓储和退换货成本。部分可拆装、包装紧凑的中小护杠仍可能直邮。

体积重（常见口径）= 长×宽×高÷计泡系数。实际计费重通常取实重与体积重的较大者；具体系数以物流商为准。

# 8. 知识产权与车型适配：机会分析不能替代检索

| 风险类型 | 常见表现 | 基础动作 |
| --- | --- | --- |
| 商标/兼容性表述 | 标题、图片或产品上使用车厂Logo；“for 某车型”写法不规范 | 区分兼容说明与来源暗示，检查商标使用 |
| 版权 | 角色图案、车贴、图片、说明书、营销素材 | 确认素材来源与授权 |
| 外观设计 | 独特造型、装饰盖、护罩、灯具外观 | 按目标销售国检索外观专利 |
| 实用/发明专利 | 快拆、锁止、安装、减震等结构 | 按功能结构与权利要求检索 |
| 适配责任 | 车型年份、孔距、接口、左右侧不匹配 | 建立车型适配表并做装车验证 |

|  | 边界 数据池只能提示“可能需要核查”的风险，不能证明无侵权。正式开发前应在目标销售国进行专业检索或法律审核。 |
| --- | --- |

# 9. 从产品类型落到具体商品：TOP3不是简单选销量前三

产品类型确认后，再在类型内挑代表性商品。建议先过滤销量低于该场景中位数的商品，然后计算商品级机会分。

| 商品级维度 | 权重 | 内部构成 |
| --- | --- | --- |
| 需求验证 | 35% | 销量（对数分位） |
| 商业价值 | 30% | 估算GMV 60% + 售价40% |
| 质量基础 | 15% | 评分 |
| 评论空白 | 20% | 评价数反向60% + 评论密度反向40% |

## 9.1 每个候选商品必须呈现的证据

原始商品名、可点击链接和产品图片。

单价、销量、评价数、评分、估算GMV。

车型/年份/通用性；无法识别时写“需核实”。

物流形态、主要机会理由和主要风险。

|  | 选品原则 TOP3应覆盖“最强需求验证”“最好商业效率”“最有评论空白”等不同证据，而不是重复列出三条相似爆款。 |
| --- | --- |

# 10. 最终推荐要分层，而不是只给一个排行榜

| 层级 | 典型条件 | 行动 |
| --- | --- | --- |
| 核心规模机会 | 容量大、中位销量高、价格带成立、竞争不过度集中 | 立即做供应链、成本和样品验证 |
| 差异化机会 | 市场成熟但评论壁垒或同质化高，可通过功能/材质/套装突破 | 先定义差异化方案，再找供应链 |
| 验证机会 | 款式少、GMV/SKU高，但样本或车型覆盖有限 | 小批量测试，补充外部市场数据 |
| 谨慎/观察 | 头部品牌/IP强、物流不经济、适配复杂或评分门槛高 | 暂缓，除非具备独特资源 |

## 10.1 推荐3—5个产品时的写法

## 1. 结论：为什么现在值得进入。

## 2. 证据：细分商品数、GMV、GMV/SKU、中位销量、Top3、价格与评论。

## 3. 打法：通用款还是车型款；功能、材质、套装或价格差异化。

## 4. 履约：直邮、平台仓或海外仓的前提条件。

## 5. 风险：物流、适配、售后、评分门槛、品牌与IP。

## 6. 验证动作：下一步要拿到哪些供应链或市场证据。

# 11. Excel交付标准：让结论可追溯

建议工作簿至少包含以下工作表。所有数字结论都能回到原始商品；图片、链接和名称必须保留。

| 工作表 | 核心内容 |
| --- | --- |
| 01_口径说明 | 数据时间、币种、GMV口径、缺失值处理、分类规则、评分权重 |
| 02_场景总览 | 一级场景的完整指标与排序 |
| 03_细分机会 | 产品类型指标、机会指数、排名与推荐层级 |
| 04_候选商品 | 原始名称、图片、链接、价格、销量、评价、评分、GMV、车型 |
| 05_物流拆分 | 轻小件、软包、重型/大体积商品及物流判断 |
| 06_复核清单 | 模糊分类、IP、车型、重量尺寸、数据异常的待确认项 |

## 11.1 表格质量检查

标题行完整，无空白列名；数值列为真正的数字格式。

按场景、产品类型、机会排名排序；筛选和冻结窗格可用。

链接可点击，图片与对应商品不串行。

公式与展示值一致，百分比、币种和小数位统一。

原始数据不被覆盖；分类和人工复核有单独字段。

# 12. 一次完整分析的执行清单

## 1. 确认文件、字段、币种、销量周期和数据日期。

## 2. 清洗价格、销量、评分、评价数，去重并保留原始证据。

## 3. 按真实消费场景初分，并人工复核高价值和模糊商品。

## 4. 计算场景层指标，只用于确定优先下钻方向。

## 5. 把优先场景拆成真实竞争单元：产品类型、物理形态、车型/通用。

## 6. 在细分层重算指标和机会指数，诊断Top1/Top3来源。

## 7. 将轻小件、软包与重型/大体积分开评估履约。

## 8. 检查品牌、素材、结构专利、车型适配与售后风险。

## 9. 每个优先赛道选3个证据型商品，不简单照搬销量前三。

## 10. 输出3—5个重点推荐，写清机会、打法、风险和验证动作。

## 11. 检查Excel图片、链接、公式、排序、表头和结论可追溯性。

|  | 最终判断标准 好的选品结论不是“这个市场卖得多”，而是“在足够细的竞争单元里，需求、客单价和商业效率成立；头部优势可解释且可复制；物流、适配与IP风险在能力范围内”。 |
