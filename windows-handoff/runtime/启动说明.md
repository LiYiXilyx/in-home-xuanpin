# Temu 选品运营台启动说明

## macOS：Temu Operator Launcher V1

在 Finder 中打开：

```text
/private/tmp/temu-multi-category-safety-v1/启动 Temu 运营台.app
```

双击后会检查现有服务、必要时在后台启动 Dashboard、等待明确 health identity，然后用系统默认浏览器打开 `http://127.0.0.1:37821/`。正常成功流程不显示 Terminal。

```text
TEMPORARY_DEPLOYMENT_PATH = YES
```

该入口当前绑定临时 worktree 和本机固定 config，不是长期部署方案。路径缺失时 HARD FAIL，不会 fallback。它只启动运营台，不启动 Chrome/Temu/Extension，不创建 Campaign，不修复 Active Pool，也不开始采集。详细说明见 `docs/TEMU_OPERATOR_LAUNCHER_V1.md`。

## Windows 旧启动方式

日常操作不需要打开 CMD，也不需要手工输入 Chrome 启动命令。

## 标准启动流程

1. 双击根目录的 `启动Temu采集Chrome.vbs`。
2. 在打开的采集 Chrome 中人工登录 Temu，确认 `Germany / English / EUR`，进入摩托配件类目并选择 `Top Sales`，等待真实商品卡片显示。
3. 双击根目录的 `启动Temu运营台.vbs`。
4. 在运营台点击“验证当前页面”。只有页面状态显示 `READY` 后，才开始 100、300 或 1000 条采集。

## 两个启动文件的区别

- `启动Temu采集Chrome.vbs`：只启动带 CDP 9222 的专用 Chrome，使用 `C:\TemuExternalChrome`；不会强制打开或跳转 Temu URL。
- `启动Temu运营台.vbs`：只启动运营台并连接已经运行的采集 Chrome；不会启动、关闭或导航 Chrome。

## 页面异常时

如果出现 `Oops! The items are gone`、`No results`、网络错误、登录页或验证码：

1. 不要开始采集，不要把空页面写入商品池。
2. 在采集 Chrome 中人工处理登录或验证码。
3. 从 Temu 首页重新进入目标类目，不复用带会话参数的旧 URL。
4. 商品卡片和 Top Sales 正常后，再回运营台点击“验证当前页面”。

运营台关闭或 Chrome 重启后，重新执行上述四步即可。系统会刷新 CDP 连接，不会继续使用重启前的旧浏览器 session。
