# 人工绑定＋影刀点击：独立测试版

此目录为新增测试，不修改原采集插件或1688应用。尚未完成真实鼠标联调，勿用于整批生产任务。

## 安装
1. VMLogin扩展管理中加载本目录 extension。测试时关闭其他Temu采集扩展，避免重复读取/提交；保留其文件，随时可切回。
2. 影刀新建独立应用“Temu辅助采集测试”。新建Python模块，将 module1.py 内容粘贴保存。
3. 在新应用图像库中录入三个目标，名称必须为：测试_采集（测试插件采集按钮）、测试_更多（See more）、测试_重试（实际出现的Try again或Try more）。不要修改原1688应用资源。
4. 添加调用模块main，args使用JSON字符串：{"profile_id":"你的VMLogin配置ID","minutes":5,"target":5,"execute":false}。
5. VMLogin打开类目页，人工检测、绑定，保持商品页前台。先运行execute=false校验。
6. 校验通过后才改execute=true进行小批测试。脚本将移动鼠标，不要同时运行1688搜图或其他桌面自动化。

## 行为
校验与绑定始终人工完成。影刀截图定位后鼠标点击采集；看到保存回执才滚动。VMLogin执行滚动和状态读取，不用JS点击。See more点击后等待新商品；重试最多一次，失败停止。插件“停止辅助采集”会阻止下一步，正在进行的接口/图像定位可能需要返回后才能结束；也可在影刀停止任务。

## 限制
图像目标必须现场录入，浏览器缩放和页面样式变化可能需更新。代码只通过语法检查，未验证VMLogin实际返回格式及现场定位。现有运营台控制页未接入此测试版；从新影刀应用启动。没有自动采集成功保证，不处理或绕过验证码。
