# 机会商品差评采集

1. 启动运营台和 VMLogin 的 Temu-DE-Test 配置，把 VMLogin 当前标签切到 Temu。
2. 在机会商品页面勾选要分析的商品（每批最多 20 件），点击“采集勾选商品的差评”。
3. 系统通过 VMLogin 本地 API 打开商品详情、核对商品 ID、打开评论、读取和滚动评论弹窗。此入口不连接 CDP，不需要点击采集插件，也无需反复手动点击评论筛选或加载。
4. 只保存明确识别为 1 星或 2 星、日期有效的评论。自动打开 Rating filters，依次选择 1 star 和 2 star，各自滚动到加载末尾；每个星级最多 200 轮。未识别、到达加载末尾或轮次上限不代表已取得全部历史差评。
5. 在每件商品下面点击“查看已采差评”。验证码、登录、页面变化或网络异常会暂停并保留已保存内容。人工处理后点击“继续上次采集”。继续时重新打开当前商品，从头加载并去重，已完成商品不重跑。
6. 可以点击“暂停采集”，等待当前 API 调用和批次保存结束。不要同时运行截图队列或手动切换 VMLogin 当前标签。服务重启后任务变为暂停，需人工继续。

评论存放在 state/opportunities/opportunities.db 的 opportunity_negative_reviews 表，任务进度在 opportunity_review_jobs 表。关联商品 ID，同一商品即使在多个机会分组出现，也复用同一份评论。原正式商品池和旧评论数据不会被覆盖。

上架时间暂不推测，页面显示未知。最早已采差评不是最早上架日期。差评样本数量不能作为整体差评率。

旧 Day9 评论任务保留原实现，本次入口为机会商品新增 VMLogin API 采集，运营人员请使用机会商品页面的差评按钮。
