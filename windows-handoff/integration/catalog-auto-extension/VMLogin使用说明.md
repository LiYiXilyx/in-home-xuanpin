# 独立类目自动采集 0.3.1

入口：http://127.0.0.1:37822/catalog-auto 。运营台侧栏和截图队列页也有入口。

## 首次升级
1. 在 VMLogin 扩展管理页重新加载本文件夹的独立自动采集扩展，确认版本 0.3.1。
2. 刷新 Temu 类目页，让新版插件加载。旧页面未刷新时仍是旧脚本。
3. 在运营台创建或继续类目采集任务。
4. 打开类目自动采集控制台，链接留空使用 VMLogin 当前页面；填写类目链接则打开该链接。
5. 点击检测并绑定，通过后开始自动采集。

使用现有 Temu-DE-Test 的 VMLogin profile，需先打开该浏览器并保持目标标签页为类目页；不要求浏览器窗口始终处于前台。截图队列与类目自动采集不能同时运行。手动插件未改动；不要同时手动采集。

## 实现及停止规则
- 本机 Node 服务调用 VMLogin API 的 ExecuteScript 接口执行滚动和按钮点击，并通过 openurl 接口打开类目页面；不是鼠标坐标模拟，不保证降低风控概率。
- 独立插件保留原来的网络补充、商品解析、页面检测、绑定、去重、批次保存和检查点接口，只接收解析/保存指令；不再自行循环滚动。
- 每轮间隔固定 6 秒。See more 后必须出现新商品，且连续三次检查内容稳定，才继续；最多等待 15 秒（另加 API 往返耗时）。
- Try again 最多自动重试一次，重试前等待 10 秒；再次出现进入暂停，等待人工恢复。验证码/访问限制、页面切换、任务切换停止。
- 暂停和停止在当前接口结束后的检查点生效，不取消已提交的保存；已成功保存的数据保留。
- 刷新或关闭控制台网页不停止后台采集；要停止请点击停止。后台服务重启后不自动续跑，必须重新检测。
- 达到目标、最长时间或连续三次无法滚动结束。新增 0 仅表示不以新增数量结束，异常和页面停滞仍会结束。

## 验证
控制器自动测试覆盖目标停止、持久化、验证码、页面切换、单次重试、加载稳定、暂停停止及截图互斥；浏览器模拟页验证桥接请求去重和任务一致性。尚未使用新版扩展进行真实 Temu 连续采集，首次运行需确认插件已重新加载。
