# Temu 类目自动滚动采集（独立版）0.1.0

加载目录：F:\TemuWindows\handoff-20260907\integration\catalog-auto-extension

在 VMLogin 的 Temu-DE-Test 内打开扩展管理，开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。保留原手动插件，自动运行时不要同时点击手动采集。刷新 Temu 类目页面后，左侧出现独立面板。

操作：检测页面 → 绑定页面 → 设置目标 → 开始自动采集。
最多 10 屏、目标新增最多 100 件；每屏等待 3.5 秒。目标是停止阈值，完整批次可能超过目标。连续三屏入库数量不增长即结束。页面进入后台、URL/任务变化或采集校验失败即停止。暂停/停止在当前请求完成后生效。结束后再次运行需要重新检测绑定。刷新页面不自动续跑。

本插件复制了手动版解析、健康检查、绑定和提交核心，source-hashes.json 记录复制时原文件哈希。原目录未修改。自动采集沿用现有任务和后端预览数据，后端暂仍记录兼容的 MANUAL_BIND_PASSIVE_CAPTURE 模式；并非独立数据库，不创建或激活商品池。

首版在 VMLogin 页面内直接滚动，无需代理 API 或 VMLogin 外部控制 API；使用既有代理配置。不截图，不主动下载单品图片（网页自身加载仍消耗代理流量）。不点击验证码、不自动登录、不自动换代理。

离线检查通过：目标停止、三次无新增停止、屏数上限、页面异常停止、JavaScript 语法、所复制原文件哈希不变。尚未加载新扩展做真实页面端到端试运行。

回退：禁用此独立扩展，继续使用原手动插件。禁用不删除已采集业务数据。

0.1.2：可见且可用的 See more 自动点击一次，等待最多15秒确认出现新商品ID；未加载则停止，不反复点击。达到屏数或新增目标后不再加载更多。

0.2.0：取消10屏限制。默认新增300件或30分钟，先到停止；新增0仅按时间停止；时间含暂停，单个进行中请求结束后停止。间隔默认6秒，可设5–60秒。最长1–240分钟。Try again/验证码/加载失败停止。不改变正式商品池。

0.2.3：See more 后必须出现新商品，商品ID/标题/价格/图片链接/卡片文字连续3次（每次500ms）无变化且无可见加载指示才继续；15秒未稳定停止。每轮6秒默认间隔不变。
