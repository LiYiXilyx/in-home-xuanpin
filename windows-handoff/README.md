# Windows 运营台源码快照（2026-09-10）

来源：当前运行的 Windows 交接版。为避免覆盖仓库原有目录，此版本独立存放于 windows-handoff。

runtime 为运营台源码，integration 为手动采集扩展、VMLogin 及截图/差评采集服务。保留两者相对目录关系。

此目录不是完整数据备份：不含数据库、商品图片、Excel、账号配置、依赖、模型及运行日志。部署时安装依赖并单独迁移 state 配置及数据；部分脚本仍含原机器路径，换机器需调整。请勿直接覆盖生产数据。

当前包含影刀一键找货、动态等待、停止续跑、按池切换、每商品随机5条候选导入、部分成果提前复核、批次归档、原商品图片显示、复核回收站及彻底删除、采集页面顺序整理。业务目录为 F:\Temu运营数据；旧数据需单独迁移。已实测11件商品及55条候选；整批50件连续运行和验证码异常尚未全面验证。integration/yingdao/module1.py 为当前接入模块；它依赖影刀应用内原有元素和图像资源，不能单独替代整个影刀应用。原应用完整备份保存在本机 yingdao-flow-backups，不纳入此源码仓库。
